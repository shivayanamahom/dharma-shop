# Журнал версий

## 0.1.0-dev.1 — 2026-10-13 (первая dev-сборка, репозиторий закрытый)

Первая сборка для проверки на чистой Joomla. Требования: Joomla 6.0+, PHP 8.3+, MySQL 8+. Установка: **Система → Установка → Расширения → Загрузить файл пакета** (`pkg_dharmashop-0.1.0-dev.1.zip`). Контрольная сумма — в файле `.sha256` релиза.

**Состав пакета:** компонент Dharma Shop (каталог, группы вариантов, поля, фильтр, поиск, корзина, оформление, заказы, покупатели, доставка, оплата, склады, избранное, акции и скидки, настройки, раздел «Помощь»); компонент «Посадочные страницы»; модули (корзина, избранное, поиск, фильтр, категории, товары); плагины полей, уведомлений (почта, Telegram), доставки (стандартная, курьер, самовывоз), оплаты (стандартная, тестовая), акций (купоны, скидка от суммы), SEO (Open Graph, Schema.org), нарезки изображений, задач планировщика, системные (меню, позиции, связанные товары, слайдер, лайтбокс); общие макеты; плагин для карты сайта стороннего компонента.

**По умолчанию выключены:** тестовая оплата (песочница), плагин карты сайта, скидка от суммы (включите в **Расширения → Плагины** при необходимости).

**Проверено:** автоматические проверки заказов, фильтра, посадочных страниц и прав (`dev/`); замеры на 100 тыс. товаров; аудиты безопасности и SEO (`docs/AUDIT_*.md`); установка пакета на чистую Joomla 6.1.3 (56 таблиц, все расширения на месте).

**Не входит:** экспорт и импорт данных (в разработке, `docs/DATA_EXCHANGE_PLAN.md`), программа лояльности, вкладка обновления частей из GitHub.

**Известно:** версия остаётся 0.1.0 в манифестах; до выхода из dev не рассчитывайте на обновление поверх без резервной копии базы.
