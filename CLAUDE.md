# Правила Claude Code для Dharma Shop

Перед любой работой прочитай [`AGENTS.md`](AGENTS.md) — это основной источник правил, решений и текущего состояния проекта. Если этот файл и `AGENTS.md` расходятся, выполняй `AGENTS.md`.

## Документация в том же изменении

Каждое функциональное изменение сразу документируй в той же работе: обновляй `docs/HELP.md` и профильное руководство, а при изменении архитектуры или публичного контракта — также `docs/DEVELOPER_GUIDE.md`, `docs/ARCHITECTURE.md` и/или `docs/TRIGGERS.md`. После изменения Form XML перегенерируй `docs/SETTINGS_REFERENCE.md` командой `python3 dev/generate-help-settings.py`.

Исключение — чисто косметическая правка, которая меняет только оформление и не влияет на поведение, смысл или сценарии пользователя. Не откладывай документацию функциональности на отдельную задачу.
