# Dharma Shop — размеры изображений

Плагин группы `dharmashop`, входит в `pkg_dharmashop`. Требует компонент Dharma Shop, Joomla 6+, PHP 8.3+ и GD. Создаёт производные при обращении; исходники не изменяет.

Настройки: **Магазин → Настройки → Изображения → Размеры изображений по контекстам**. Размер `0` означает авто, `0 × 0` — исходник. Формат «По общей настройке WebP» следует переключателю конвертации в этой же вкладке; email-контексты используют JPEG/PNG.

Общее качество JPEG/WebP (20–100, по умолчанию 82) задаётся рядом с переключателем WebP, действует также на загрузчик и миграцию; в строках контекстов качества нет. Сохранённые исходники не перекодируются.

Кеш: `images/dharmashop/cache/resized/v2/<2 символа хеша>/<ещё 2>/<файл>`. Контекст выбирает пресет, но не входит в путь или ключ. Для одного исходника одинаковые размеры, режим, итоговый формат и качество используют один файл/URL/lock во всех контекстах. Имена формата нормализуются до реального JPEG/PNG/WebP/AVIF; качество JPEG/WebP не влияет на ключ PNG.

Имя начинается с границ размера, режима и качества: `600x400-contain-q82-<хеши>.webp`, `autox400-contain-q82-<хеши>.webp` (для PNG — `lossless`). Папки создаются по мере обращения, запись с блокировкой и атомарным переименованием. Изменение исходника или настроек даёт новый вариант. Старый `v1` и исходники не удаляются, автоматической чистки нет.

## Добавление места вывода

1. Зарегистрируйте ID и размеры в `Administrator\Image\ImageContexts::SIZES` компонента.
2. Добавьте подпись RU/EN `COM_DHARMASHOP_IMAGE_CONTEXT_<ID>` (ID в верхнем регистре, точки → `_`).
3. Вызывайте `Dharma\Component\DharmaShop\Administrator\Image\ImageUrl::resolve($path, 'your.context')` в макете, экранируйте результат перед HTML. Для общей карточки передайте `imageContext` в displayData.
4. Добавьте строку контекста в сохранённых настройках магазина. Новые стандартные строки не заменяют сохранённые пользовательские настройки автоматически.

Событие `onDharmaShopImagePrepare`: аргументы `request: ImageRequest` (source/context readonly, url изменяемый) и `settings: Registry`. Подписчик меняет `$request->url`.

Полный реестр, ограничения, совместимость с WebP и правила хранения: `docs/IMAGE_RESIZE.md` в исходном репозитории Dharma Shop.
