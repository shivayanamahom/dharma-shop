# Страницы каталога

Страницы магазина создаются как пункты меню Joomla. Откройте раздел **Меню**, выберите нужное меню и нажмите **Создать пункт меню**. Выберите тип страницы Dharma Shop и заполните его параметры.

- Для общего списка товаров выберите страницу каталога.
- Для конкретного раздела выберите категорию.
- Для страниц других типов выберите соответствующий вид Dharma Shop, например бренд или избранное.

Сохраните пункт меню и откройте его на сайте. Если нужная страница не появляется в выборе, сначала создайте и опубликуйте соответствующую запись магазина.

Основные параметры каталога находятся в **Dharma Shop → Настройки**. Параметры конкретной категории могут задавать собственный вид и число товаров; если значение не задано, применяется общее значение магазина. Чтобы добавить подборки рядом с каталогом, разместите [модули сайта](ADMIN_MODULES.md).

Табличный вид содержит две колонки: товар и цена. Дополнительные характеристики в нём не выводятся; у группы варианты также не перечисляются под названием.
