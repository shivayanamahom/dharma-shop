# Поиск по настройкам магазина (C72)

Дата: 2026-10-08. Пользователь согласовал поиск над вкладками по примеру поиска настроек телефона, включая небольшое исключение для JavaScript в админке. Поиск реализован в компоненте, без системного плагина, переопределения com_config и изменений Joomla.

## Подключение

Непостоянное поле `_settings_search` типа `settingssearch` в первом fieldset config.xml. `admin/src/Field/SettingssearchField.php` выводит только оболочку поиска и регистрирует `com_dharmashop.settings-search` через WebAssetManager. У search-input нет name: запрос не отправляется и не записывается в params. PHP ограничивает вывод страницей administrator / com_config / component=com_dharmashop.

`media/js/settings-search.js` ждёт штатный joomla-tab и переносит оболочку непосредственно перед #configTabs. Без JS оболочка скрыта; сами настройки остаются нативными. CSS нет, оформление/подсветка — Bootstrap. Файлы входят в существующие папки src/media манифеста, версия 0.1.0.

## Поведение

- По уточнению пользователя скрыта внутренняя левая навигация com_config по другим компонентам: `#component-form > .main-card-columns > #sidebar` получает hidden/d-none, соседний #config — col-12 вместо col-md-9. Только на странице настроек Dharma Shop, через тот же скрипт и классы Bootstrap; основное меню Joomla не затрагивается.
- Индекс из готовой формы: названия и собственные описания control-group, путь из вкладки/legend/родительского subform. Индексирует реальные созданные строки конструктора, без содержимого template будущих строк.
- Для строки конструктора путь содержит её название (label/title), иначе номер. Значения настроек, технические пароли/ключи и выбранные значения в индекс поиска не включаются; название строки — единственное читаемое значение для подписи пути.
- Части слов, несколько слов одновременно, ё/е; приоритет совпадения в названии. Результаты порциями по 20, «Показать ещё». Пустой запрос скрывает результаты; нулевой результат сообщает об отсутствии.
- Нажатие результата открывает вкладку штатным activateTab, раскрывает details, прокручивает к полю и фокусирует доступный элемент. В мобильном accordion уже открытую вкладку не закрывает. Подсветка Bootstrap на три секунды; убираются только добавленные поиском классы. Учтён prefers-reduced-motion.
- Поля showon доступны в поиске даже на неактивной вкладке. Если скрыты условием, показан бейдж и условия показа, переход направляется к видимому полю условия. Значения условия и showon поиск не меняет, скрытые настройки насильно не раскрывает.
- Enter — первый результат, стрелки — переход между результатами, Escape/«Очистить» — очистка. Enter в строке поиска не сохраняет форму. Кнопки результатов type=button.
- Изменение/добавление/удаление строк обновляет индекс (MutationObserver + input/change, объединены requestAnimationFrame). Запросов на сервер, аналитики и хранения истории нет.

### Важное ограничение группировки Form XML

Поиск строит индекс по уже выведенным Joomla `control-group`. Поэтому настройка не появится в поиске, если Joomla не отрисовала её в форме. В Joomla 6 штатный `com_config` рендерит вложенные fieldset отдельно, а прямые поля родительского fieldset при наличии вложенных групп не выводит. Не смешивайте поля и дочерние fieldset в одном блоке: выносите поля в отдельные leaf-fieldset на одном уровне. Исправление для карточек/страницы товара и общих настроек корзины внесено в `com_dharmashop/admin/config.xml`; имена параметров и сохранённые значения не меняются.

## Загрузка центра настроек

Настройки остаются в одном центре и на одной странице. Вкладки и поиск не заменяются отдельными страницами. Для раздела «Расширения» обычный рендер формы использует сохранённые сведения о версиях библиотек без сетевых запросов; актуальные версии проверяются только по явному нажатию кнопки. Проверка открывает ту же страницу после обновления кеша.

Поэтапная загрузка содержимого вкладок с сохранением единой оболочки — следующий этап оптимизации, ещё не реализован. При её разработке нужно сохранить поиск по всем параметрам, переходы между разделами и частичное сохранение без перезаписи значений незагруженных групп.
