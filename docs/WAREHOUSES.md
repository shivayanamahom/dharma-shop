# Склады (C81)

Дата: 2026-10-08. По запросу пользователя: склады — отдельная сущность магазина с разделом в меню админки; способы доставки (самовывоз — пункты выдачи, курьер — откуда считать расстояние) и другие части магазина берут склады из справочника, а не хранят свои копии.

## Модель

Таблица `#__dharmashop_warehouses`: `id`, `title`, `alias` (уникальный), `image`, `address`, `phone`, `email`, `hours` (часы работы), `info` (дополнительная информация: как добраться, что взять), `ready_term` (срок готовности самовывоза), `lat`/`lon` `decimal(9,6)` (координаты; необязательны), `state`, `access`, `ordering`, `checked_out*`. Индекс `(state, ordering)`.

Координаты вводятся одним полем в формате Яндекса `[55.753994, 37.622093]` (широта, долгота; допустимы запись без скобок и десятичная запятая) и хранятся в `lat`/`lon` (`Administrator\Warehouse\Coords`). Склад без координат на карте не показывается и в расчёте расстояния не участвует.

## Раздел админки

«Склады» — пункт меню рядом с «Доставкой» (плагин `plg_system_dharmashopmenu`), виды `warehouses`/`warehouse`: список (поиск, фильтр состояния, порядок перетаскиванием, публикация, удаление; колонка «Есть на карте»), форма (вкладка «Основное»: блок «Место» — изображение, адрес, координаты; блок «Контакты и условия» — телефон, e-mail, часы работы, срок готовности, дополнительная информация; справа публикация и доступ). Право `dharmashop.warehouses.manage` (плюс обычные `core.create/edit/edit.state/delete`).

## Использование в коде

- `ShopServices::warehouses()` → `WarehouseService::byIds(array $ids): Warehouse[]` — опубликованные склады с учётом уровня доступа посетителя, в порядке справочника; `Warehouse` (`id`, `title`, `address`, `phone`, `email`, `hours`, `info`, `readyTerm`, `lat`, `lon`, `image`, `coords()`).
- Поле формы `warehouseselect` (`Administrator\Field\WarehouseselectField`, атрибут `multiple`) — выбор складов из справочника в настройках способов доставки (префикс полей `Dharma\Component\DharmaShop\Administrator\Field`).
- Изображение склада пока нигде не выводится; при первом выводе — свой контекст изображений (правило проекта, `docs/IMAGE_RESIZE.md`).

## Дальше

Самовывоз берёт пункты выдачи из справочника (вкладка «Склады» способа), курьер — склады отправки для расчёта расстояния. Склады понадобятся для остатков по складам, самовывоза в карточке товара и других задач.
