# Настройки магазина

Общие параметры собраны на одной странице: откройте **Dharma Shop → Настройки**. Вкладки разделяют их по задачам: магазин, каталог, отображение магазина, корзина, изображения, фильтр, SEO и избранное.

## Быстро найти параметр

Используйте поиск над вкладками настроек. Введите часть названия или подсказки. Результаты ведут к соответствующим полям; очистите поиск, чтобы вернуться к полной форме.

## Как применяются значения

Общее значение задаёт поведение по умолчанию. Если для конкретной категории или пункта меню доступно и заполнено собственное значение, оно применяется только там. Пустое поле обычно означает, что нужно унаследовать значение выше; сохраняйте настройки и проверьте страницу сайта после изменения.

В модуле есть собственные параметры показа: они действуют на этот экземпляр и не меняют другие модули на той же странице.
