# Модуль товаров

`mod_dharmashop_products` выводит подборку товаров и мета-товаров. Модуль можно разместить на главной или любой другой странице и независимо настроить каждый экземпляр.

## Источник и подбор

- **Товары** — подборка опубликованных товаров в доступных посетителю категориях. Можно выбрать условия отбора и сортировку по дате, цене или названию, ограничение количества и направление.
- **Ранее просмотренные** — до 20 товаров, открытых в этом браузере за последние 180 дней. История хранится в cookie этого сайта, не привязана к учётной записи; текущая открытая карточка не выводится в блоке.
- Дополнительные условия можно задать по категориям, брендам, бейджам, значениям фильтруемых полей и числовым/диапазонным полям. Значения выбранных категорий, брендов и бейджей объединяются внутри своей группы по ИЛИ. Для разных групп задаётся общее И/ИЛИ. У каждого поля выбора соблюдается собственная настройка логики значений.
- В числовых полях можно добавить до 12 строк с нижней и верхней границей. Повторные условия для одного поля пересекаются.
- Доступ и публикация проверяются для товара, его категории и предков. Непубличные или недоступные записи не попадают в результат.

## Формат и макет

- **Отдельные товары** выводят каждый товар сам по себе.
- **Мета-товары и отдельные товары** сворачивают подходящие товары одной группы в одну карточку; товар без группы остаётся отдельной карточкой. Условия сначала применяются к товарам, поэтому группа показывается, если подходит хотя бы один её товар.
- Сетка, горизонтальный список и слайдер используют общие карточки компонента по умолчанию. Отключите «Карточка компонента», чтобы использовать макеты модуля. Их можно переопределить в шаблоне сайта в `html/layouts/modules/mod_dharmashop_products/product.php` и `group.php`.
- Слайдер подключает общий Swiper через WebAssetManager. Количество видимых карточек, шаг, скорость, стрелки, индикаторы, зацикливание и автопрокрутка настраиваются отдельно. Полоски пагинации используют те же классы Bootstrap, что и в слайдере категорий.

## Несколько экземпляров на одной странице

У каждого экземпляра собственные параметры, ID DOM и управление слайдером. Можно включить исключение повторов: каждый такой экземпляр исключает товары и группы, уже выведенные предыдущим экземпляром с этой настройкой. Результат зависит от порядка модулей в позиции. История просмотров не отключает кеш всей страницы, но персональный блок сам работает без кеша Joomla.

Чтобы разместить блок на главной, выберите позицию главной страницы в шаблоне и назначьте модуль пункту меню главной. На тестовом сайте для проверки создана отдельная позиция `home-products`, выводимая только на домашнем пункте меню.

## Ограничения

История просмотров хранит только идентификаторы товаров и не гарантирует показ удалённых, снятых с публикации или ставших недоступными товаров. В модуле нет AJAX-подгрузки и персонального хранения на сервере. Версия расширения следует версии пакета `0.1.0`.
