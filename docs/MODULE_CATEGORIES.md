# Модуль категорий Dharma Shop

`mod_dharmashop_categories`, Joomla 6+, версия 0.1.0. Настройки — штатная форма Joomla, собственных административных JS/CSS нет.

## Выборка и отображение

- **Подкатегории:** непосредственные дочерние категории выбранного раздела. «Весь каталог (корень)» — верхний уровень. Множественный список исключений действует в этом режиме.
- **Выбранные категории:** множественный выбор произвольных категорий. Порядок показа — порядок дерева каталога, одинаковый в обоих режимах.
- Учитываются публикация и уровни доступа категории **и всех её предков**. Бренды/бейджи не входят в выборку. Пустой выбор не выводит блок.
- Выборка модуля независима от параметра `show_in_list` страницы каталога: состав задают режим, выбор и исключения самого модуля. Ограничения публикации/доступа сохраняются.
- **Сетка:** общий помощник `Grid`, 1–6 колонок; упрощённая адаптивная настройка или отдельные значения xs/sm/md/lg/xl/xxl.
- **Аккордеон:** штатный Bootstrap collapse. Заголовок раскрывает непосредственные подкатегории и ссылку на все товары раздела. Категория без дочерних разделов — обычная ссылка. Подкатегории всех показанных заголовков выбираются одним ограниченным запросом; лимит на раздел 1–100, default=12. Можно раскрыть первую категорию и разрешить несколько открытых панелей. ID зависят от ID модуля и категории; разные экземпляры независимы. Все заголовки имеют одинаковый размер и начертание. Если включены изображения, миниатюра 48 × 48 выводится рядом с названием раздела, включая категории без детей. Подкатегории оформлены отдельными Bootstrap-карточками. Используются собственные макеты `layouts/accordion.php` и `layouts/accordion-heading.php`.
- **Слайдер:** общий Swiper системного плагина через WAM, без повторной библиотеки. Видимое число карточек отдельно для xs/sm/md/lg/xl/xxl, расстояние, скорость перехода, стрелки, индикаторы, цикл, автопрокрутка и интервал. Недостаточное для цикла число карточек отключает loop. Единственная карточка сохраняет заданную ширину; недоступные элементы управления скрыты. Без библиотеки — адаптивная сетка. JS модуля подключается только для слайдера.
- **Использовать макеты компонента:** актуально для сетки и слайдера — карточка из общей настройки `category_card_layout`, включая переопределения Joomla. При выключении — собственные карточки `layouts/grid.php` и `layouts/slider.php` модуля.
- Все настройки модуля находятся в первой штатной вкладке «Модуль». Настройки сетки, аккордеона и слайдера показываются через `showon` в зависимости от выбранного макета. Отдельных вкладок макетов/кнопки нет; служебные вкладки Joomla сохранены.
- Изображение и интро включены по умолчанию. Интро — `params.introtext` категории, выводится текстом без HTML. Количество товаров и диапазон цен **выключены по умолчанию**. Переключатели действуют с обоими источниками карточек.
- Счётчик включает опубликованные товары вложенных категорий по индексу `product_categories`. До 10 000 — точное значение, далее `10000+`. Цена — минимум/максимум опубликованных товаров того же индекса; формат как в карточках подкатегорий компонента, одинаковые границы не повторяются. Если товаров/цен нет — диапазон скрыт.

## Лимит и кнопка каталога

Лимит 1–100, по умолчанию 6. Загружается максимум `limit + 1` категорий; дополнительная строка служит признаком наличия продолжения и не рендерится. `COUNT(*)` по всему списку категорий не нужен.

Кнопка «Показать все» включена по умолчанию, появляется только при превышении лимита **после** отбора/исключений/проверки доступа. Можно отключить её, изменить текст и CSS-классы (`btn btn-outline-primary` по умолчанию).

Ссылка автоматически находит доступный для языка/пользователя пункт меню корня каталога (`category` или `categories`, id 0/1), предпочитая список товаров. Если нужный пункт не найден — стандартный маршрут `com_dharmashop&view=category&id=0`, который строит штатный роутер. Можно вручную выбрать пункт меню; это также позволяет направить кнопку на специально подготовленную страницу. Числовые Itemid/домены в коде не зашиты.

## Изображения и переопределения

Собственные контексты `module.categories.grid`, `module.categories.accordion` и `module.categories.slider`, по умолчанию 600 × 400, режим contain, общий формат/качество магазина. Все карточки используют `ImageUrl::resolve`. При использовании карточки компонента контекст передаётся через `$displayData['imageContext']`; её обычный вывод сохраняет `category.card`.

Три новых контекста автоматически дополняют набор размеров, сохранённый до установки модуля, как в обработчике изображений, так и в административной форме. Существующие строки не меняются. Явная строка 0 × 0 отключает преобразование соответствующего контекста; отключённый плагин/общий ресайз оставляет исходник. В старом переопределении карточки нужно сохранить передачу `imageContext`, иначе оно продолжит использовать собственный фиксированный контекст.

Пути переопределений:

- Оболочка модуля: `templates/<шаблон>/html/mod_dharmashop_categories/default.php`.
- Оболочка слайдера: `templates/<шаблон>/html/mod_dharmashop_categories/slider.php`.
- Собственные карточки и статистика: `templates/<шаблон>/html/layouts/modules/mod_dharmashop_categories/{grid,accordion,accordion-heading,slider,stats}.php`.
- Карточка компонента: `templates/<шаблон>/html/layouts/components/dharmashop/category-card/<макет>.php`.

Данные карточки: `item` (params — Registry), `url`, `imageContext`, `showImage`, `showIntro`, `showCount`, `showPrices`, `productCount`, `priceRange`, `fields` (пустой массив). Для собственных карточек также `renderStats(array $displayData)`. Дополнительные поля категорий модуль не загружает.

## Скорость

1. Только ограниченная выборка нужных столбцов категории; никаких товаров/вариантов/дополнительных полей при выключенной статистике.
2. Для верхнего уровня — **один запрос**. Для вложенных категорий — максимум ещё один пакетный запрос недостающих предков. `Router::primeCategories()` подготавливает маршруты до рендера карточек, исключая запросы по одной категории/предку.
3. При включении количества и/или цен — **один дополнительный SQL-запрос**, составленный из ограниченных подзапросов для показанных карточек. В аккордеоне это карточки подкатегорий; его заголовки не считают статистику. Счётчик ограничен 10 001 строками на категорию; минимум/максимум читаются по `idx_l_price`. Выключенные показатели не запрашиваются. Нет полного GROUP BY по товарному каталогу, выборки всех ID, JSON SQL и OFFSET. Аккордеон добавляет один пакетный запрос непосредственных детей (`child_limit + 1` на раздел), маршруты детей используют уже подготовленных предков.
4. Сетка не подключает JS/CSS модуля. Аккордеон использует только `bootstrap.collapse` через WAM при наличии раскрываемых разделов (зависимость `core` добавляет Joomla, дубликаты объединяет WAM). Слайдер — общий preset `dharmashop.swiper` и отдельный небольшой инициализатор `mod_dharmashop_categories.slider`, с независимыми селекторами/элементами управления. Собственного CSS нет.
5. Изображения lazy/async, производные повторно берутся из файлового кэша общего плагина. HTML/выборка специально не кэшируются между пользователями: изменение доступа, категории или настроек видно сразу.

Замер 2026-10-09 на **текущем небольшом каталоге test.test**, 9 повторов после прогрева, 3 карточки сетки/слайдера. Это подготовка данных, без холодного подключения БД, полной страницы и генерации изображений:

| Выборка | Статистика | Запросов | Медиана |
|---|---|---:|---:|
| Верхний уровень | нет | 1 | 0,633 мс |
| Верхний уровень | количество + цены | 2 | 1,284 мс |
| Подкатегории смартфонов | нет | 2 | 0,582 мс |
| Подкатегории смартфонов | количество + цены | 3 | 0,901 мс |

Число товаров не участвует в обычной выборке категорий. Скорость проверки дерева зависит от числа/глубины категорий и индексов Joomla; замер на 100 тысячах категорий не проводился. При включении счётчика стоимость ограничена указанным потолком на каждую показанную категорию. Первый ресайз нового исходника может занимать больше времени, чем повторный вывод.

## Установка и тестовый шаблон

Модуль включён в `pkg_dharmashop.xml`, `build.sh` и `dev/sync.sh`; можно установить отдельно из его папки штатным установщиком Joomla. Версия пакета не меняется.

На test.test установлен модуль **128**, «Dharma Shop — Категории», **не опубликован**. В установленном шаблоне `dharma_starter` добавлена позиция **`catalog-categories`** после `main-top`, перед основной строкой контента, на ширину контейнера. Позиция выбрана у модуля; публикацию/привязку к страницам делает пользователь. Изменены только `templates/dharma_starter/index.php` и `templateDetails.xml`; шаблон является отдельным проектом и в пакет магазина не включён. Точная правка позиции сохранена в `dev/patches/dharma_starter-catalog-categories.patch` для переноса в отдельный проект шаблона; установщик магазина её автоматически не применяет.

Практически проверены оба режима и исключения, пустой выбор, лимит/кнопка, оба источника карточек, аккордеон в браузере (раскрытие/сворачивание и независимость экземпляров), загрузка обработанных изображений, нативная административная форма и доступность позиции. Статистика сверена с текущими индексными данными. Публикация модуля не выполнялась.
