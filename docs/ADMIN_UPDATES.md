# Обновления Dharma Shop

Dharma Shop обновляется штатными средствами Joomla: у пакета и **у каждого плагина, модуля и компонента** есть собственная версия и собственная лента обновлений. Если изменился один плагин, обновляется только он, а не весь магазин.

## Как это работает

- При установке пакета Joomla запоминает адрес ленты каждого расширения (Система → Установка → Источники обновлений: записи «Dharma Shop: …»).
- Ленты лежат в публичном репозитории [dharma-shop-updates](https://github.com/shivayanamahom/dharma-shop-updates), архивы — в его разделе «Releases». В каждой записи ленты есть контрольная сумма SHA-256: Joomla проверяет скачанный архив и не устанавливает его при несовпадении.
- Версия расширения меняется только тогда, когда менялось само расширение. Версия пакета `pkg_dharmashop` меняется при каждом выпуске; обновление пакета ставит всё сразу и добавляет новые расширения, если они появились.

## Обновить

1. **Система → Обновление → Расширения → Найти обновления** (или команда `php cli/joomla.php update:extensions:check`).
2. Отметьте нужные расширения и нажмите **Обновить**. Можно обновить только плагин, только модуль или пакет целиком.
3. Перед обновлением сделайте резервную копию базы и файлов; обновление ядра `com_dharmashop` на рабочем сайте удобно проводить в режиме обслуживания.

Пока проект в ранней разработке, сборки помечены как **разработческие**. Чтобы Joomla их показывала, откройте **Система → Установка → Расширения → Параметры** и в «Минимальной стабильности» выберите «Разработка». Настройка общая для всех расширений сайта.

## Уведомления

Обычные средства Joomla работают с Dharma Shop без доработок: иконка «Обновления расширений» в панели управления и задача планировщика «Update Notification» (письмо суперпользователям).

## Если обновления не находятся

- **Источники обновлений** (Система → Установка → Источники обновлений): адреса записей «Dharma Shop: …» должны вести на `shivayanamahom.github.io/dharma-shop-updates`, записи должны быть включены. Кнопка «Перестроить» восстанавливает адреса из манифестов.
- **Сервер не видит интернет.** Joomla скачивает ленты через cURL. Если сайт запущен на локальном сервере с VPN/прокси в режиме туннеля, а в настройках сети не указан DNS, cURL с библиотекой c-ares не находит адреса (в сообщении: «Could not resolve host»). Добавьте DNS-серверы (например, `1.1.1.1`, `8.8.8.8`) в настройках сетевого подключения или отключите туннель.
- **Минимальная стабильность** выше, чем у сборки (см. выше).
- Если файл архива повреждён или подменён, Joomla сообщит о несовпадении контрольной суммы; установка не начнётся.

Установка и обновление «вручную» остаются доступны: **Система → Установка → Расширения → Загрузить файл пакета** (архивы — в разделе Releases репозитория обновлений).
