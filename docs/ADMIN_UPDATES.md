# Обновления Dharma Shop

Dharma Shop обновляется штатными средствами Joomla: у пакета и **у каждого плагина, модуля и компонента** есть собственная версия и собственная лента обновлений. Если изменился один плагин, обновляется только он, а не весь магазин.

## Как это работает

- При установке пакета Joomla запоминает **один общий источник обновлений «Dharma Shop»** (Система → Установка → Источники обновлений): коллекция со списком всех частей и их версий, проверка занимает один запрос. Подробную ленту конкретного расширения Joomla читает только когда вы его обновляете.
- Ленты лежат в публичном репозитории [dharma-shop-updates](https://github.com/shivayanamahom/dharma-shop-updates), архивы — в его разделе «Releases». В каждой записи ленты есть контрольная сумма SHA-256: Joomla проверяет скачанный архив и не устанавливает его при несовпадении.
- Версия расширения меняется только тогда, когда менялось само расширение. Версия пакета `pkg_dharmashop` меняется при каждом выпуске; обновление пакета ставит всё сразу и добавляет новые расширения, если они появились.

## Обновить

1. **Система → Обновление → Расширения → Найти обновления** (или команда `php cli/joomla.php update:extensions:check`).
2. Отметьте нужные расширения и нажмите **Обновить**. Можно обновить только плагин, только модуль или пакет целиком.
3. Перед обновлением сделайте резервную копию базы и файлов; обновление ядра `com_dharmashop` на рабочем сайте удобно проводить в режиме обслуживания.

Пока проект в ранней разработке, сборки помечены как **разработческие**. Чтобы Joomla их показывала, откройте **Система → Установка → Расширения → Параметры** и в «Минимальной стабильности» выберите «Разработка». Настройка общая для всех расширений сайта.

## Страница «Dharma Shop → Обновления»

Отдельная лёгкая страница (пункт в меню магазина; значок с числом показывает, сколько расширений ждут обновления). Во вкладке **Настройки → Расширения** осталась только ссылка на неё: таблица вынесена оттуда, чтобы не утяжелять страницу настроек. На странице — все части магазина (пакет, компоненты, плагины, модули): установленная и доступная версия и состояние. Кнопки:

- **Проверить обновления** — один небольшой запрос к индексу версий, затем штатный поиск Joomla только для расширений с более новой версией (около секунды). Страница настроек сама в интернет не ходит; если сервер не видит интернет, проверка сразу сообщит об этом.
- **Обновить до X** у строки — обновляет только это расширение.
- **Обновить всё (N)** — ставит пакет целиком, если он обновился (в нём все части), иначе по очереди все найденные расширения.
- **Откатить** у строки — возвращает файлы расширения к предыдущей версии из ленты: архив скачивается, проверяется контрольная сумма SHA-256, затем штатная установка. Предыдущие версии хранятся в ленте (последние пять). Изменения базы данных не откатываются (они обратно совместимы), перед откатом сделайте резервную копию.
- **Какие сборки показывать** — общая настройка Joomla «Минимальная стабильность»: разработческие, бета, кандидаты в релиз или только стабильные. Та же настройка действует на штатный экран «Обновление» (меняется в Система → Установка → Расширения → Параметры).

Кнопки доступны суперпользователю (право «Настройки» магазина и право на «Установку расширений»). Обновляет штатный механизм Joomla, поэтому результат и проверка контрольной суммы такие же, как на экране «Система → Обновление → Расширения».

## Уведомления

Обычные средства Joomla работают с Dharma Shop без доработок: иконка «Обновления расширений» в панели управления и задача планировщика «Update Notification» (письмо суперпользователям).

## Если обновления не находятся

- **Источники обновлений** (Система → Установка → Источники обновлений): запись «Dharma Shop» (тип «Коллекция») должна вести на `shivayanamahom.github.io/dharma-shop-updates/updates/dharma-shop.xml` и быть включена. Кнопка «Проверить обновления» во вкладке «Расширения» приводит запись в порядок сама; «Перестроить» в списке источников восстанавливает адреса из манифестов.
- **Сервер не видит интернет.** Joomla скачивает ленты через cURL. Если сайт запущен на локальном сервере с VPN/прокси в режиме туннеля, а в настройках сети не указан DNS, cURL с библиотекой c-ares не находит адреса (в сообщении: «Could not resolve host»). Добавьте DNS-серверы (например, `1.1.1.1`, `8.8.8.8`) в настройках сетевого подключения или отключите туннель.
- **Минимальная стабильность** выше, чем у сборки (см. выше).
- Если файл архива повреждён или подменён, Joomla сообщит о несовпадении контрольной суммы; установка не начнётся.

Установка и обновление «вручную» остаются доступны: **Система → Установка → Расширения → Загрузить файл пакета** (архивы — в разделе Releases репозитория обновлений).
