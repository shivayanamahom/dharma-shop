# Обновления Dharma Shop

Dharma Shop обновляется штатными средствами Joomla и **целиком, одним пакетом**: пакет `pkg_dharmashop` приносит новые версии всех своих частей (компонентов, плагинов, модулей) и добавляет новые, если они появились. Отдельных обновлений плагинов и модулей нет, поэтому после обновления у всех расширений Dharma Shop одна и та же версия.

## Как это работает

- Адрес ленты хранится только у пакета. При установке Joomla создаёт источник обновлений «Dharma Shop» (Система → Обновление → Источники обновлений).
- Лента лежит в публичном репозитории [dharma-shop-updates](https://github.com/shivayanamahom/dharma-shop-updates), архивы пакета — в его разделе «Releases». В записи ленты есть контрольная сумма SHA-256: Joomla проверяет скачанный архив и не устанавливает его при несовпадении.

## Обновить

1. **Система → Обновления → Расширения → Найти обновления** (или команда `php cli/joomla.php update:extensions:check`).
2. Отметьте **Dharma Shop (пакет)** и нажмите **Обновить**.
3. Перед обновлением сделайте резервную копию базы и файлов; обновление ядра `com_dharmashop` на рабочем сайте удобно проводить в режиме обслуживания.

Пока проект в ранней разработке, сборки помечены как **разработческие**. Чтобы Joomla их показывала, откройте **Система → Установка → Параметры** и в «Минимальной стабильности» выберите «Разработка». Настройка общая для всех расширений сайта.

## Уведомления

Обычные средства Joomla работают с Dharma Shop без доработок: иконка «Обновления расширений» в панели управления и задача планировщика «Update Notification» (письмо суперпользователям).

## Если обновления не находятся

- **Источники обновлений** (Система → Обновление → Источники обновлений): запись «Dharma Shop» должна вести на `shivayanamahom.github.io/dharma-shop-updates` и быть включена. Кнопка «Перестроить» восстанавливает адреса из манифестов.
- **Сервер не видит интернет.** Joomla скачивает ленты через cURL. Если сайт запущен на локальном сервере с VPN/прокси в режиме туннеля, а в настройках сети не указан DNS, cURL с библиотекой c-ares не находит адреса (в сообщении: «Could not resolve host»). Добавьте DNS-серверы (например, `1.1.1.1`, `8.8.8.8`) в настройках сетевого подключения или отключите туннель.
- **Минимальная стабильность** выше, чем у сборки (см. выше).
- Если файл архива повреждён или подменён, Joomla сообщит о несовпадении контрольной суммы; установка не начнётся.

Установка и обновление «вручную» остаются доступны: **Система → Установка → Расширения → Загрузить файл пакета** (архивы — в разделе Releases репозитория обновлений).
