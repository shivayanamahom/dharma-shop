# Модули сайта

Модуль выводит отдельный блок на странице: товары, категории, фильтр, поиск, корзину или избранное. На одной странице можно разместить несколько модулей товаров с разными подборками.

## Разместить модуль

Откройте **Система → Управление → Модули сайта**, нажмите **Создать** и выберите модуль Dharma Shop. В карточке модуля задайте:

1. Понятное имя, например «Популярные товары — главная».
2. Состояние **Опубликовано**.
3. Позицию шаблона, в которой должен находиться блок.
4. Страницы показа — все или выбранные пункты меню.
5. Параметры модуля и сохраните запись.

Для нескольких модулей используйте разные имена и условия отбора, чтобы потом различать их в списке.

## Модуль товаров

В параметрах модуля выберите источник подборки, количество карточек и формат: сетка, список или слайдер. Источники отбора позволяют ограничить товары категориями, брендами, бейджами и значениями полей. Режим **Ранее просмотренные** показывает посетителю товары, с которыми он уже взаимодействовал на сайте.

Карточка товара берётся из макета компонента либо из переопределения шаблона — согласно настройке модуля. Подробно: [модуль товаров](MODULE_PRODUCTS.md).
