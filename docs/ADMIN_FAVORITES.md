# Избранное

Сердце на карточке товара добавляет товар в список посетителя. Модуль **Dharma Shop — Избранное** показывает счётчик и ссылку на страницу списка.

## Создать страницу списка

В разделе **Меню** создайте пункт меню Dharma Shop типа **Избранное**. В его параметрах можно задать заголовок страницы, вступительный и полный тексты, число колонок и макет карточек.

Общие настройки находятся в **Dharma Shop → Настройки → Избранное**. Там можно включить или выключить избранное и выбрать макет карточек по умолчанию. Если функция выключена, сердца и модуль не показываются; ранее сохранённые списки не удаляются.

Гость может пользоваться списком без входа. После входа список переносится в аккаунт. Для просмотра списков покупателей в панели управления пользователю нужны соответствующие права доступа.
