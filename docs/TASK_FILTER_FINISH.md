## Решения реализации

Три значения политики модуля: «Как в каталоге», «Группы с подходящим вариантом», «Отдельные товары». Отображение не должно менять состав подходящих товаров или разрешать недоступные группы/участников. Не загружать все карточки вариантов заранее. Состояние/политика сохраняются в сортировке, пагинации, AJAX, чипах и истории. При нескольких модулях инициатор определяется сервером по доступному опубликованному модулю; браузер не передаёт SQL или произвольную конфигурацию.

Режим live — дизъюнктивные фасеты: считать по всем условиям кроме собственного поля. Системные справочники должны соблюдать ту же семантику. Ограничение кандидатов/времени даёт обозначенный approximate fallback, выбранные значения остаются доступными для снятия. Базовые данные должны учитывать видимость и единицы текущего режима; ACL не обходится предрасчётом.
