# Права доступа и роли

Доступом сотрудников управляет штатная система прав Joomla. Права проверяются на нескольких уровнях, каждый нижний наследует верхний и может его переопределить: **компонент → категория → товар**. Суперпользователь может всё.

## Где что настраивается

- **Весь магазин:** **Dharma Shop → Настройки → Права доступа** (верхний уровень, действует всюду, пока не переопределено ниже).
- **Категория, бренд, бейдж:** вкладка **«Права доступа»** в форме записи. Можно, например, отдать категорию «Мебель» её менеджеру: он создаёт и правит товары только в ней.
- **Товар:** вкладка **«Права доступа»** в карточке товара (редко нужна: товар наследует права своей категории).

## Какие права есть

| Право | Что разрешает |
|---|---|
| Доступ к компоненту, Настройки, Все права | вход в магазин; общие настройки; назначение прав |
| Создать, Править, Изменить состояние, Удалить | работа с товарами и справочниками; на уровне категории и товара — только с ними |
| Править свои | редактировать только товары, созданные этим пользователем |
| Управлять полями и группами полей | структура характеристик: создание и изменение полей и групп полей |
| Управлять группами товаров | группы вариантов (цвет, размер…), оси выбора, генерация вариантов |
| Управлять статусами заказов | сами статусы (названия, цвета, эффекты) |
| Управлять заказами | просмотр заказов, повтор уведомлений |
| Смена статуса заказа | перевод конкретного заказа в другой статус |
| Покупатели: просмотр, Избранное: просмотр | списки покупателей и избранного покупателей |
| Склады, Доставка, Оплата | управление соответствующими разделами |

Выбрать **готовую группу** в карточке товара могут все, кто правит товары; **создавать и менять** группы — только с правом «Управлять группами товаров».

## Готовые роли (рекомендуемые наборы)

| Роль | Группа пользователей Joomla | Права |
|---|---|---|
| Контент-менеджер | «Менеджер» или своя | Доступ к компоненту, Создать, Править, Изменить состояние (при необходимости только на нужных категориях) |
| Менеджер категории | своя | те же права, но заданы на вкладке «Права доступа» нужной категории, а не на всём магазине |
| Менеджер каталога | своя | контент-менеджер + «Управлять полями и группами полей» и «Управлять группами товаров» |
| Менеджер заказов | своя | Доступ к компоненту, «Управлять заказами», «Смена статуса заказа», «Покупатели: просмотр» |
| Оператор склада и доставки | своя | Доступ к компоненту, «Склады», «Доставка» |
| Администратор магазина | «Администратор» | все права, включая «Настройки», «Оплата», «Управлять статусами заказов» |

Пример: чтобы менеджер «Мебели» работал только со своей категорией, дайте его группе «Доступ к компоненту» на всём магазине, а «Создать», «Править» и «Изменить состояние» — на вкладке «Права доступа» категории «Мебель» (на всём магазине оставьте «Не задано»).

## Что видит сотрудник

Боковое меню **Dharma Shop** показывает только те разделы, на которые у сотрудника есть права (например, без права «Управлять полями» нет пунктов «Поля» и «Группы полей»), а прямой адрес запрещённого раздела отвечает «У вас нет прав доступа».

## Обновление с прежней версии

При обновлении пакета новые отдельные права получают те группы, которые раньше могли то же самое общим правом: «Управлять полями» и «Управлять группами товаров» — группы права «Править»; «Управлять статусами заказов» — группы прежнего права статусов; «Смена статуса заказа» — группы «Управлять заказами». После обновления откройте **Настройки → Права доступа** и при необходимости уточните выбор. Права, заданные вручную, обновление не меняет.

## Посадочные страницы

У компонента посадочных страниц свои права (**Компоненты → Посадочные страницы → Параметры → Права доступа**): доступ, создать, править, изменить состояние, удалить.
