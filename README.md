# Dharma Shop

Универсальный лёгкий e-commerce для Joomla 6+: базовый компонент `com_dharmashop` (каталог, поля, корзина, заказы) и расширения — плагины, модули, отдельные компоненты. Нативный интерфейс Joomla, масштаб от 100 до 100 000+ товаров без смены архитектуры: цена, остаток и значения полей хранятся в индексируемых столбцах, без `JSON_*` и `LIKE '%…%'` на путях витрины.

**Статус:** ранняя разработка (версия `0.1.0`, релиза ещё нет). Работает сквозной сценарий «каталог → корзина → оформление → заказ → письмо»; проверяется на тестовом сайте. Для боевых магазинов пока не предназначен.

## Что уже есть

- **Каталог:** товары, категории, бренды и бейджи (все в нативных категориях Joomla), цены, скидки с таймером и автоматическим бейджем «Акция», учёт остатков с наследованием правил (товар → категория → настройки), единицы и шаг количества.
- **Витрина:** списки в виде сетки, списка и таблицы, четыре типа пагинации (обычная, AJAX, «показать ещё», бесконечная), галерея Swiper и лайтбокс Fancybox (в пакете, с обновлением библиотек из настроек), адаптивная вёрстка только на Bootstrap 5, ЧПУ как у `com_content`, SEO-шаблоны, Schema.org и соцтеги.
- **Дополнительные поля** товаров и категорий: группы, типы, ограничения, вывод в карточке и на странице (плагины типов полей).
- **Поиск:** FULLTEXT по названию и артикулу, подсказки при вводе (модуль `mod_dharmashop_search`), раскладка и транслитерация, свои синонимы, мягкий режим для опечаток, адрес `?filter[search]=…`.
- **Корзина:** в базе, AJAX без перезагрузки, модуль со значком и боковой панелью, режим «кнопка → виджет количества», замена нулевой цены текстом («Цена по запросу»).
- **Заказы:** оформление с настраиваемыми полями контактов и согласий, гостевой заказ, покупатели, статусы с историей, страницы «Заказ оформлен», «Заказ» и «Мои заказы» (личный кабинет), письма администратору и покупателю (плагин `plg_dharmashopnotify_email`).
- **Изображения:** загрузчик с конвертацией в WebP и плагин размеров по контекстам (`plg_dharmashop_imageresize`).
- **Админка:** 100 % нативная Joomla (Form XML, searchtools, штатный тулбар), поиск по настройкам магазина.

## Что дальше

Фильтр товаров (`filter[…]`), варианты товара (оси, матрица, выбор на карточке), **избранное** (отдельный компонент), **компонент экспорта** и **компонент импорта**, **мета-вариации**, эффекты статусов (остатки и резерв), доставка и оплата плагинами, консольные команды и замеры на 100 000+ товаров. Подробный план — [docs/ROADMAP.md](docs/ROADMAP.md).

## Состав пакета

`pkg_dharmashop` ставит одним архивом: компонент `com_dharmashop`, общие макеты (`files_dharmashop_layouts`), плагины (типы полей, письма, размеры изображений, соцтеги и Schema.org, Swiper, Fancybox) и модули (`mod_dharmashop_cart`, `mod_dharmashop_search`). Сборка — `./build.sh` (результат в `dist/`), стенд и проверки — [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Требования

Joomla 6+, PHP ≥ 8.3, MySQL 8+ / MariaDB 10.6+.
