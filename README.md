# Dharma Shop

Универсальный лёгкий e-commerce для Joomla 6+: базовый компонент `com_dharmashop` (каталог, поля, варианты, корзина, заказы) и расширения — плагины, модули, отдельные компоненты. Нативный интерфейс Joomla, масштаб от 100 до 100 000+ товаров без смены архитектуры.

**Статус:** разработка, этап 0 (схема и скорость). Код пока отсутствует.

- Требования: Joomla 6+, PHP ≥ 8.3, MySQL 8+ / MariaDB 10.6+.
- Разрабатывается поэтапно; текущее состояние — [docs/ROADMAP.md](docs/ROADMAP.md).
- Для ИИ-ассистентов: начните с [AGENTS.md](AGENTS.md).
- Решения — [docs/DECISIONS.md](docs/DECISIONS.md), архитектура — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
