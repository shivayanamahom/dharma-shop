## ⚡ Архитектура и производительность

Dharma Shop спроектирован с упором на предельную производительность витрины и чистоту кода:

* **Zero-JSON Query (Никакого JSON на путях витрины):**  
  Цены, диапазоны, остатки, связи и значения пользовательских характеристик хранятся в строго типизированных индексированных столбцах (`INT`, `DECIMAL`, `VARCHAR`), а не в упакованных `JSON`-полях. Никаких медленных функций `JSON_EXTRACT` и сканирования таблиц `LIKE '%...%'`.
* **Мгновенная фасетная фильтрация:**  
  Фасетный движок (`FacetEngine` / `FilterQuery`) оперирует предварительно рассчитанными границами и битовыми индексами. На каталогах в **100 000 товаров** фильтрация по нескольким свойствам отрабатывает за **единицы–десятки миллисекунд**.
* **100% нативная экосистема Joomla 5/6:**  
  - Категории товаров, бренды и бейджи используют стандартную иерархическую структуру `#__categories` (с расширением `com_dharmashop`).
  - Формы, панели, табы (`uitab`), списки и подформы (`subform`) построены на родном Joomla Form XML.
  - Наследование прав доступа (ACL) на уровне категорий, групп и отдельных действий.
  - Управление ассетами через `WebAssetManager` (никаких несогласованных внешних скриптов).
* **Чистый фронтенд:**  
  Только семантический HTML5 и классы **Bootstrap 5**, без тяжелых сторонних фреймворков и inline-стилей. Встроенные адаптивные галереи **Swiper** и лайтбоксы **Fancybox**.

## ✨ Ключевые возможности

### 🛍 Каталог и товары
* **Категории, Бренды и Бейджи:** Нативная иерархия, вложенность без ограничений, SEO-метатеги, изображения и описания.
* **Группы и Варианты:** Самостоятельные товары объединяются в группы с общими осями (размер, цвет, объем). У вариантов индивидуальные цены, артикулы, остатки и изображения ([подробнее в VARIANTS.md](docs/VARIANTS.md)).
* **Гибкие остатки:** Наследование политик списания и отображения (Товар → Категория → Общие настройки), единицы измерения и шаг количества.
* **Умные цены и Акции:** Старая/новая цена, таймеры обратного отсчета, автоматический бейдж «Акция», промокоды (купоны) и прогрессивная скидка от суммы заказа ([ADMIN_PROMOTIONS.md](docs/ADMIN_PROMOTIONS.md)).

### 🔍 Фильтрация и поиск
* **Фасетный фильтр (`mod_dharmashop_filter`):**  
  Поддержка фильтрации по цене (двойной ползунок), наличию, бренду, бейджам и любым дополнительным полям. Логика `ИЛИ` внутри поля и `И` между полями. Вертикальный, горизонтальный и мобильный режим (выдвижная панель offcanvas). Поддержка AJAX-фильтрации с сохранением истории URL.
* **Полнотекстовый поиск (`mod_dharmashop_search`):**  
  FULLTEXT-поиск по названию и артикулу с живыми подсказками (автокомплит), устойчивостью к опечаткам, транслитерацией «на слух» (например, *айфон → iPhone*) и собственными синонимами.

### 🛒 Корзина и оформление заказа
* **AJAX Мини-корзина (`mod_dharmashop_cart`):**  
  Быстрое добавление без перезагрузки, кнопка в шапке со счётчиком и выдвижная боковая панель (Offcanvas) с предпросмотром состава.
* **Оформление (Checkout):**  
  Одностраничное оформление, гостевой заказ без обязательной регистрации, настраиваемые поля контактов и согласий на обработку данных.
* **Личный кабинет покупателя:**  
  Страница успешного оформления, трекинг статуса заказа по номеру и история заказов в профиле пользователя.

### 💳 Оплата и доставка (Плагинная архитектура)
* **Способы оплаты:** Наличные / при получении, тестовая песочница с верифицированным callback-подтверждением; возможность легкого подключения банковских эквайрингов плагинами группы `dharmashoppayment`.
* **Способы доставки:** Стандартная доставка, курьер (с расчетом по карте), самовывоз из пунктов выдачи (`dharmashopshipping`).
* **Матрица совместимости:** Настройка «какая оплата доступна для какого способа доставки».

### 📊 Импорт и Экспорт
* **Экспорт (`com_dharmashop_export`):** Профили выгрузки в **CSV, Excel (XLSX) и YML** (фиды для маркетплейсов). Фоновая генерация, постоянные ссылки на автообновляемые фиды.
* **Импорт (`com_dharmashop_import`):** Загрузка товаров, категорий, брендов и полей из **CSV и Excel**. Автоматическое сопоставление колонок, скачивание фотографий по ссылкам, предварительный аудит («будет создано / обновлено / ошибок») и безопасное применение.
* **CLI и Cron:** Запуск экспорта и импорта по расписанию в фоновом режиме через планировщик Joomla или консоль сервера.

### 🎯 SEO и Маркетинг
* **Посадочные страницы (`com_dharmashop_landing`):** Виртуальные категории на базе условий фильтра с человекопонятными URL, уникальными H1/Title/Description и автоматическим 301-редиректом с фильтра.
* **Микроразметка:** Автоматическая генерация валидной разметки **Schema.org** (`Product`, `AggregateOffer`, `Brand`, `ItemList`) и OpenGraph-тегов для соцсетей.
* **SEO-шаблоны:** Автогенерация метатегов по настраиваемым маскам `{title}`, `{brand}`, `{price}`, `{category}`.

## 🚀 Установка и быстрый старт

### Системные требования

| Компонент | Минимальная версия | Рекомендуется |
|---|---|---|
| **Joomla** | `5.2+` или `6.0+` | `6.1+` |
| **PHP** | `8.3` | `8.3+` / `8.4` (расширения `pdo_mysql`, `gd`/`imagick`, `mbstring`, `zip`) |
| **База данных** | `MySQL 8.0+` | `MySQL 8.4+` или `MariaDB 10.6+` |
| **Шаблон витрины** | Шаблон с поддержкой Bootstrap 5 (рекомендуется [`dharma-starter`](https://github.com/shivayanamahom/dharma-starter)) |

---

### Вариант 1: Прямая установка по URL в Joomla (Рекомендуется)

1. Откройте панель управления Joomla: **Система** → **Установка** → **Расширения** → вкладка **«Установить по URL-адресу»**.
2. Вставьте прямую ссылку на актуальный архив пакета:
   ```text
   https://github.com/shivayanamahom/dharma-shop-updates/releases/download/v0.1.14/pkg_dharmashop-0.1.14.zip
   ```
3. Нажмите кнопку **«Проверить и установить»**.

### Вариант 2: Загрузка архива

1. Скачайте zip-архив пакета `pkg_dharmashop-<версия>.zip` со страницы [Releases](https://github.com/shivayanamahom/dharma-shop-updates/releases).
2. В админке Joomla перейдите в **«Система → Установка → Расширения»** → вкладка **«Загрузить файл пакета»**.
3. Перетащите скачанный zip-архив в окно загрузки.

> [!TIP]
> После установки основные модули и плагины активируются автоматически инсталлятором `script.php`. Тестовая оплата (песочница), скидки от суммы заказа и плагин карты сайта остаются выключенными по умолчанию до их ручной настройки.

## 🔄 Автоматические обновления

Dharma Shop обновляется **целиком одним пакетом** штатными средствами Joomla:

1. Перейдите в **Система → Обновления → Расширения**.
2. Нажмите **«Найти обновления»**.
3. Нажмите **«Обновить»** в строке «Dharma Shop (пакет)».

Joomla автоматически скачивает проверенный архив, сверяет контрольную сумму SHA-256 и обновляет все 35 компонентов, модулей и плагинов за один шаг.

Коллекция обновлений прописана в манифесте `pkg_dharmashop.xml`:
```xml
<updateservers>
    <server type="collection" priority="1" name="Dharma Shop">https://shivayanamahom.github.io/dharma-shop-updates/updates/dharma-shop.xml</server>
</updateservers>
```

## 💻 Консольные команды Joomla CLI

Dharma Shop поддерживает выполнение ресурсоемких операций из консоли сервера без таймаутов браузера:

```bash
# Запуск профиля экспорта каталога (ID профиля = 1)
php cli/joomla.php dharmashop:export --profile=1

# Запуск импорта каталога из файла Excel
php cli/joomla.php dharmashop:import --profile=1 --file=/var/www/data/catalog.xlsx

# Пересчет поисковых индексов и фасетов
php cli/joomla.php dharmashop:reindex
```

Все консольные команды поддерживают вывод прогресса, подробные логи и могут быть прописаны в системный `crontab` хостинга.

## 🛠 Сборка пакета из исходников

Для сборки инсталляционного архива пакета `pkg_dharmashop` из исходного кода репозитория:

```bash
# Клонирование репозитория
git clone https://github.com/shivayanamahom/dharma-shop.git
cd dharma-shop

# Запуск скрипта сборки
./build.sh
```

Скрипт выполнит:
1. Валидацию языковых ключей (`dev/check-component-language-keys.py`);
2. Генерацию встроенной HTML-справки администратора (`dev/generate-help-site.py`);
3. Упаковку каждого компонента, плагина и модуля в отдельный zip-архив;
4. Формирование итогового пакета `dist/pkg_dharmashop-<версия>.zip`.
